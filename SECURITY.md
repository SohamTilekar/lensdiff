# Security Policy

## Security & Privacy Guarantee

DiffLens is designed from the ground up as a **100% static, client-side application**:
- Images uploaded, dropped, or pasted into DiffLens **never leave your web browser**.
- There are **no backend servers, external APIs, tracking telemetries, or database storage**.
- All image rendering, canvas manipulations, and metadata parsing occur entirely in local client memory.

## Reporting Security Vulnerabilities

If you discover a security vulnerability or potential privacy issue within this repository:
1. Please report it privately by emailing [sohamtilekar233@gmail.com](mailto:sohamtilekar233@gmail.com).
2. Do not open a public issue until the security report has been acknowledged and addressed.
